Cellsmith

A code editor for Excel formulas, in a side pane synced to the selected cell.

  • Auto-format deeply nested formulas, including LET and LAMBDA
  • Autocomplete and argument hints for 500+ functions, tables, names and variables
  • Live error checking before Excel rejects the formula
  • Runs entirely in your Excel. No workbook data is sent anywhere.

Install

Download manifest

A small file that tells Excel where Cellsmith lives. It contains no program code. Requires Microsoft 365 Excel.

Excel on Windows

  1. Put manifest.xml in a new folder, for example C:\CellsmithAddin.
  2. Share that folder with yourself (right-click → Properties → Sharing → Share) and copy its network path, like \\YOUR-PC\CellsmithAddin.
  3. In Excel: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Paste the path, click Add catalog, tick Show in Menu, then restart Excel.
  4. Home → Add-ins → More Add-ins → Shared Folder → Cellsmith → Add.

Excel on the web: Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in, then choose the file.
