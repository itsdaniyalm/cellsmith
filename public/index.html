Cellsmith

A code editor for Excel formulas, in a side pane synced to the selected cell.

  • Auto-format deeply nested formulas, including LET and LAMBDA
  • Autocomplete and argument hints for ~480 functions, tables, names and variables
  • Live error checking before Excel rejects the formula
  • Runs entirely in your Excel. No workbook data is sent anywhere.
